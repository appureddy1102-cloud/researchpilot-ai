          │              └───────────────▲──────────────────────────────────────────────┬────────────────┘
          ▼                              │ ResearchResult                                 │ save / load
  ┌─────────────────────────── agent/research_agent.py ───────────────┐          ┌───────▼────────┐
  │ 1 Query analysis ┐                                                │          │ database/      │
  │ 2 Planning       ┘ research_planner.py (LLM, JSON)                │          │ database.py    │
  │ 3-5 TOOL LOOP:  LLM picks tool ─► tool_selector.ToolExecutor ─►   │          │ (SQLite)       │

## Tools (all real Python functions)

| Tool (LLM name) | Module | What it really does |
|---|---|---|
| `web_search` | `tools/web_search.py` | HTTPS POST to `api.tavily.com/search`; returns title, URL, snippet, score, date |
| `read_webpage` | `tools/webpage_reader.py` | HTTP GET + BeautifulSoup cleaning; SSRF-safe; graceful failures |
| `analyze_sources` | `tools/source_evaluator.py` | Rule-based relevance / authority / freshness scores, duplicate detection |
| `extract_evidence` | `tools/evidence_extractor.py` | LLM extracts statements **with verbatim quotes**; quotes are verified against the page text and invented ones are dropped |
| `finish_research` | `agent/tool_selector.py` | Ends the loop |

## Anti-hallucination design

1. The LLM never writes URLs, dates or the reference list: those are generated by code from the stored Tavily results.
2. Evidence needs a quote that exists in the source text (`quote_in_text`).
3. The report prompt receives *only* numbered evidence and must cite with `[n]`.
4. `validate_citations` deletes any `[n]` that does not map to a real source.
5. `check_claim_support` flags cited sentences with almost no word overlap with the cited source's evidence (a heuristic sanity check, labelled as such in the UI).
6. If the LLM is down, a template report is built straight from the evidence - still cited, never invented.

## Source scoring

`overall = (0.40·relevance + 0.35·authority + w·freshness + 0.10·support) / total`, with `w = 0.25` if the question needs current information, else `0.10`.
Authority comes from the domain: government 0.95, university 0.90, intergovernmental bodies/journals ≈ 0.9, reputable news/industry 0.65–0.8,
vendor blogs ≈ 0.55-0.6, unknown sites 0.4, user-generated/social 0.1–0.3. See `KNOWN_DOMAINS` in `tools/source_evaluator.py` - edit it freely.
